# Changelog

## 0.1.0 - 2026-10-20

- Added deterministic SVG generation for panels, regular shapes, cubes, arrows and basic chart motifs.
- Added scoped curve extraction with color, dark-stroke and filled-shape masks.
- Added local VTracer output, shared-canvas assembly, module exports, curve exports and PNG previews.
- Added specification validation, generated-SVG validation, ZIP packaging and clear refusal to overwrite non-empty build directories.
- Added synthetic fixture tests, a complete local scientific-framework specification, and GitHub Actions tests.
- Excluded unverified source imagery from the public repository by default.
